# 🧮 Python Calculator (CLI)

my first project making simple python calculator
A simple command-line calculator built using Python.  
This project supports basic arithmetic operations and is created to practice Python fundamentals and GitHub workflow.

---

## 🚀 Features
- Addition
- Subtraction
- Multiplication
- Division
- Input validation using try-except
- Uses Python `match-case` (Python 3.10+)

---

## 🛠️ Technologies Used
- Python 3.10+
